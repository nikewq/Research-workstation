隐私政策 · Privacy Policy

最后更新 / Last updated: 2026-07-27
Summary (English): This app stores your data locally on your device (localStorage / IndexedDB). The developer does not operate a server that collects, stores, or sells your personal data. Two features are opt-in and involve third parties: (1) Cloud Sync, which backs up your data to a Supabase project you control access to via a random sync code you generate; (2) AI features, which are Bring-Your-Own-Key — your API key is stored only on your device and requests go directly from your device to the AI provider you choose (Anthropic, OpenAI, DeepSeek, Google, etc.), never through the developer's servers. Full details below (Chinese).

1. 这是一个什么样的应用

「博士工作台 · PhD Workstation」是一款为科研人员设计的个人生产力工具，包含任务管理、文献库、投稿追踪、专注计时、习惯打卡、反思日记等模块。本应用的核心设计原则是：你的数据默认只存在你自己的设备上，不需要注册账号即可完整使用全部功能。

2. 我们如何处理你的数据

数据类型存储位置是否上传
任务、文献、投稿记录、日记、习惯打卡、番茄计时、笔记等日常使用数据仅存于本机浏览器 / App 本地存储（localStorage / IndexedDB）否，开发者的服务器不会收集这些内容
AI 服务 API Key（如你自行配置）仅存于本机，不进入任何备份或同步否，只会在你使用 AI 功能时由你的设备直接发往你选择的 AI 服务商
云同步数据（需你主动开启）你控制的 Supabase 项目，以你本机生成的随机同步码为唯一索引是，仅在你主动打开「云同步」并保存时上传
留言墙内容（如你选择发布）公开展示的社区板块是，发布后对其他访客可见，请勿发布隐私信息

3. 云同步（可选功能）

「个人设置 → 云同步」是一个可选功能。开启后，应用会为你生成一个高强度随机同步码（约 1.8 万亿种组合），并将你的任务/日记/文献等数据打包上传到开发者使用的 Supabase（第三方后端服务）项目中，以该同步码为唯一索引。任何人只要持有你的同步码就能读取/覆盖该份数据，请像对待密码一样妥善保管，不要分享给他人。你可以随时选择不使用该功能，改用「导出数据」将 JSON 备份文件保存在自己设备上。

4. AI 功能（Bring Your Own Key）

本应用集成的 AI 辅助功能（写作润色、文献解读、AI 建议等）需要你自行在设置中填入你自己申请的 API Key（支持 Anthropic Claude、OpenAI、DeepSeek、Google Gemini 等服务商，以及本地私有部署的兼容接口）。Key 仅保存在你的设备本地，不会被打包进云同步或导出备份，不会经过开发者运营的任何服务器中转。使用 AI 功能时，你输入的内容会由你的设备直接发送给你所选择的第三方 AI 服务商，其处理与保留方式受该服务商自身隐私政策约束，与本应用开发者无关。

5. 第三方接口调用

以下功能会在使用时向对应的第三方公开接口发起请求，均为学术公开数据检索，不携带你的个人身份信息：

  • 文献检索与元数据：OpenAlex、Semantic Scholar、Crossref、arXiv
  • PDF 解析、公式渲染、图表绘制、ZIP 解压：PDF.js、KaTeX、Chart.js、JSZip（均通过 jsdelivr / cdnjs 公共 CDN 加载脚本本身，不上传你的数据）
  • 你如自行配置 Zotero API Key，用于同步你自己的 Zotero 文献库
  • 访客计数：使用不蒜子（busuanzi）做匿名页面浏览量统计，不采集可识别个人身份的信息

6. 我们不做什么

  • 不收集你的姓名、邮箱、位置等个人身份信息（应用本身无需注册账号）
  • 不向第三方出售或出租你的数据
  • 不投放广告、不做用户行为跟踪分析
  • 不会未经你主动操作而上传你的数据

7. 数据删除

本地数据：直接清除 App 数据 / 卸载即可完全删除。云同步数据：在「云同步」中可清空对应同步码下的记录；如需协助彻底删除，可通过下方联系方式与开发者联系。

8. 儿童隐私

本应用面向科研人员设计，不面向 13 周岁以下儿童，也不会主动收集儿童个人信息。

9. 政策更新

如本政策发生重大变更，我们会更新本页顶部的日期，并视情况在应用内提示。

10. 联系方式

如对本隐私政策有任何疑问，请通过 GitHub 仓库 提交 Issue 联系开发者。
